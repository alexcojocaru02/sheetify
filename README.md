# Sheetify

Sheetify is a Flutter-based sheet music application designed to help musicians browse, organize, and view sheet music across multiple platforms.

## About the project

This repository contains the source code for **Sheetify**, a cross-platform app built with Flutter. The project is intended to be **inspired by the Sheet Music Free app**, while evolving into its own experience with a modern interface and a flexible codebase.

## Technologies used

The project is built with a mix of native and cross-platform technologies, including:

- **C++** – 44%
- **CMake** – 36.4%
- **Dart** – 10.7%
- **HTML** – 3.6%
- **C** – 2.8%
- **Swift** – 2.2%
- **Other** – 0.3%

## Repository structure

This repo includes platform-specific folders and Flutter app code for:

- `lib/` – main Dart application code
- `android/` – Android platform integration
- `ios/` – iOS platform integration
- `linux/` – Linux desktop support
- `macos/` – macOS desktop support
- `web/` – web support
- `windows/` – Windows desktop support
- `test/` – automated tests

## Getting started

To run the project locally, make sure you have Flutter installed, then use the standard Flutter workflow:

```bash
flutter pub get
flutter run
```

For platform-specific builds, follow the Flutter documentation for Android, iOS, desktop, or web.

## Goals

Sheetify aims to become a clean, practical, and cross-platform sheet music experience, with room for features such as:

- sheet music browsing and organization
- fast access to scores
- a smooth reading experience
- cross-platform availability

## Note

This project is currently in active development and may change significantly as features are added and refined.
